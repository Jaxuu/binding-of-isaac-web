## 1. 系统概述
定义 **3 种普通敌人**（Gaper / Pooter / Horf）与 **1 个 Boss**（Monstro）的完整规格，以及房间刷怪波规则。所有敌人复用 `02-combat.md` 第 7 节的 AI 模式模块。

**通用参数（所有敌人共享）**：
| 参数 | 值 | 说明 |
|------|-----|------|
| 受击闪白 | 6 帧 | 纯白覆盖 |
| 受击击退 | `min(damage×6, 300)` px/s | 方向=子弹方向 |
| 接触伤害 | 1 心 | 玩家接触即扣血（受玩家无敌帧约束） |
| 死亡动画 | 8 帧爆浆 | +屏幕震动 4px |
| 激活条件 | 进入房间即 ACTIVE | 无睡眠 |
| 坑洞交互 | 地面单位不可穿过 | 飞行单位（`flying:true`）可越 |

## 2. 普通敌人规格

### 2.1 Gaper（蹒跚者）· 追击型
> 原作最具代表性的基础敌人：一张哭嚎的大脸，摇晃着冲向玩家。

| 属性 | 值 |
|------|-----|
| `id` | `gaper` |
| HP | **10** |
| 移速 | **70 px/s** |
| 碰撞半径 | **18 px** |
| AI 模式 | `CHASER` |
| 攻击 | 仅接触伤害 |
| 掉落 | 按 `03-items-stats.md` 6.2 通用掉落 |
| 飞行 | 否 |

**行为状态机**：
```
IDLE ──(玩家进入房间)──▶ CHASE
CHASE：朝玩家当前位置直线移动（速度 70）
        每 30 帧随机偏移 ±15° 一次（模拟"蹒跚"）
受击 ──▶ HURT(6帧, 闪白+击退) ──▶ CHASE
HP≤0 ──▶ DYING(8帧) ──▶ 掉落判定 & 移除
```
- **视觉（交 art-director）**：苍白脸 + 大张的黑色嘴 + 两行眼泪；粗黑描边；移动时上下轻微晃动（2px 正弦）。
- **难度定位**：教学型，用来教玩家"保持距离并射击"。

### 2.2 Pooter（飞行喷吐者）· 飞行远程型
> 一颗会飞的圆脑袋，每隔一段时间朝玩家吐出一颗弹。

| 属性 | 值 |
|------|-----|
| `id` | `pooter` |
| HP | **8** |
| 移速 | **55 px/s**（漂移） |
| 碰撞半径 | **16 px** |
| AI 模式 | `KITER` + `FLYER` |
| 攻击 | 发射单弹，伤害 **1 心** |
| 攻击冷却 | **90 帧**（1.5s），±10 帧抖动 |
| 飞行 | **是**（可越坑洞/岩石） |
| 掉落 | 通用掉落 |

**行为状态机**：
```
KITER：
  与玩家距离 < 200px → 远离
  与玩家距离 > 320px → 靠近
  否则 → 横向漂移（垂直玩家视线方向，速度 55）
  周期性：每 90 帧 → ATTACK（朝玩家发射一颗弹，弹速 180 px/s）
受击 ──▶ HURT ──▶ KITER
HP≤0 ──▶ DYING ──▶ 移除
```
- **弹**：圆形，半径 7px，存活 4s 或飞出房间；命中玩家 → 1 心。
- **视觉**：飞行的白/灰球体 + 小翅膀 + 一双眼睛 + 小嘴。

### 2.3 Horf（静止吐弹者）· 射击型（静止）
> 一个钉在地上的肉块，只会转头发射弹丸。（本作做"静止吐弹"，符合 GDD 需求；原作 Horf 亦有跳跃变体，本作取静止版）

| 属性 | 值 |
|------|-----|
| `id` | `horf` |
| HP | **12** |
| 移速 | **0**（静止） |
| 碰撞半径 | **18 px** |
| AI 模式 | `TURRET` |
| 攻击 | 三向弹幕（120° 扇形，朝玩家） |
| 攻击冷却 | **110 帧**（~1.83s） |
| 飞行 | 否 |
| 掉落 | 通用掉落 |

**行为状态机**：
```
IDLE ──(玩家进入房间)──▶ ACTIVE
ACTIVE：
  每 110 帧 → ATTACK
  ATTACK：发射 3 颗弹，以玩家方向为中心 ±20° 展开（弹速 200 px/s）
  其余时间：静止（可加"张嘴"蓄力动画预警）
受击 ──▶ HURT ──▶ ACTIVE
HP≤0 ──▶ DYING ──▶ 移除
```
- **蓄力预警**：攻击前 20 帧播放"张嘴膨胀"动画，给玩家躲避窗口（**公平性关键**）。
- **视觉**：肉色/粉色椭圆身体 + 一嘴黑牙 + 小眼睛。

## 3. Boss · Monstro（蒙斯特罗）

> 原作首层 Boss：一颗巨大、臃肿、涕泪横流的怪脸。跳跃压地 + 喷射三向弹幕。

### 3.1 基础属性
| 属性 | 值 |
|------|-----|
| `id` | `monstro` |
| HP | **300** |
| **碰撞体** | **多圆复合体**（见 §3.1.1，取代原单一 r=52） |
| 移速 | 跳跃位移，非连续移动 |
| 伤害（压地） | **1 心**（玩家在落点范围内） |
| 伤害（弹幕） | **1 心/弹** |
| 免疫于击退 | 是（Boss 不位移） |
| 受击闪白 | 6 帧 |
| 死亡 | 20 帧大爆浆 + 屏幕震动 14px + 掉落（见 `03` 6.3） |

#### 3.1.1 碰撞体裁定（v1.3 · 主理人游承峰裁决）
> **背景**：原 GDD 用单一 r=52 圆，而 art-bible §2.4 的 Monstro 视觉尺寸仅 64×58（视觉半径 ~32）——会在轮廓外 ~40px 的空气中判定受伤，**违背支柱 P1「公平」**。裁定改为**复合体 + 命中/接触分离**：

**（a）接触 / 推挤（玩家贴身判定用）—— 3 圆复合体**
```js
const MONSTRO_CONTACT_HITBOX = [
  { ox:   0, oy: +4, r: 26 },   // 主体（下腹，最靠近玩家）
  { ox: -16, oy: -6, r: 20 },   // 左上（脸/眼区）
  { ox: +16, oy: -6, r: 20 },   // 右上
];
```
- **随 §2.4 的 scale / 帧同步**：上述偏移与半径 × Monstro 当前 `scale`（蓄力压扁 / 跳跃拉伸时同步变换）。
- 判定：玩家圆与**任一**子圆相交 → 触发接触伤害（受玩家无敌帧约束，见 `02` §5.1）。

**（b）子弹命中（玩家射击判定用）—— 单圆 r = 30**
- **比接触判定宽松**：单圆 r=30 覆盖复合体范围，避免"打中却不算"的挫败感（对玩家友好）。
- 子弹与 r=30 圆相交 → 命中扣血（敌人无受击无敌帧，见 `02` §4.4）。

**设计理由**：接触严（3 圆贴合视觉轮廓，公平）+ 命中松（单圆 r=30，手感爽）= 同时满足支柱 P1（公平）与 P2（手感）。**已同步工程（程基岩）。**

### 3.2 三阶段行为
**阶段切换**：HP 阈值 `>200`（阶段1）→ `100–200`（阶段2）→ `<100`（阶段3 狂暴）。

```
┌─────────────────────────────────────────────────────────┐
│ 阶段 1（HP > 200）：基础模式                              │
│  循环：JUMP → LAND → SPIT(3向) → 等待 60帧 → 回到 JUMP     │
│  JUMP：蓄力 30 帧（下蹲动画）→ 跳向玩家位置（空中 25 帧）    │
│  LAND：落地 → 屏幕震动 14px → 落点 60px 半径内伤害 1 心     │
│  SPIT：发射 3 颗弹（±20°）朝玩家                          │
│                                                          │
│ 阶段 2（100 ≤ HP ≤ 200）：加速模式                        │
│  同上，但：等待时间 60→30 帧；跳跃蓄力 30→18 帧            │
│  新增：每 2 次跳跃后追加一次"五向弹幕"（±20°,±40°）        │
│                                                          │
│ 阶段 3（HP < 100）：狂暴                            │
│  同上，但：等待 30→15 帧；弹速 +30%（200→260 px/s）        │
│  新增：SPIT 改为 5 颗弹连续两轮（间隔 15 帧）              │
│  跳跃落点预测变为"玩家当前位置+速度×10帧"（预判）           │
└─────────────────────────────────────────────────────────┘
```

### 3.3 行为状态机
```
SPAWN(30帧无敌+入场) ──▶ IDLE
IDLE ──(计时)──▶ CROUCH(蓄力) ──▶ JUMP(空中) ──▶ LAND(落地判定)
LAND ──▶ SPIT(发射弹幕) ──▶ COOLDOWN(等待) ──▶ IDLE
受击 ──▶ HURT(6帧, 不位移) ──▶ 返回当前
HP 跨过阈值 ──▶ PHASE_UP(10帧咆哮) ──▶ 新阶段 IDLE
HP≤0 ──▶ DYING(20帧) ──▶ 掉落 & 开门
```

### 3.4 平衡校验
- 玩家基础 DPS ≈ 21 → 击杀 300 HP 需约 **14.3 秒**（不含走位损耗）。加上躲招，实际 30–50 秒，符合"小型 Boss 战"时长。
- 若玩家拿到 Polyphemus（damage 17.5, fireDelay 17 → DPS≈62）→ 约 5s，但需精准；合理。
- **主导策略风险**：远程风筝（Pooter 类打法）能让玩家无伤磨 Boss？→ Monstro 的**跳跃**专门惩罚站桩风筝（落点跟随），设计上已抑制。

### 3.5 视觉（交 art-director）
- 巨型苍白脸，一双巨大下垂的泪眼，大张的黑嘴（喷射弹幕时可见）。
- 蓄力时下蹲、体积压扁；跳跃时离地、投影变椭圆；落地时溅起"肉屑"粒子。
- 阶段 3 时脸泛红（狂暴状态视觉提示）。
- **跨成员命名对齐**：渲染配方见 `design/art-bible.md` §2.4（函数名建议 `drawMonstro`），配色 `C_MONSTRO_BODY #b06a52` 等。

### 3.6 敌人/Boss 可访问性（对齐 `design/accessibility.md` §3–§4）

> 回应可访问性契约中影响敌人设计的 2 项：**弹幕减速辅助** 与 **形状冗余**。

**（1）弹幕减速辅助对 Boss 的影响**
| 参数 | 默认 | 辅助模式（`ASSIST`） | 说明 |
|------|------|---------------------|------|
| Monstro 弹幕速度 | 200 / 260(狂暴) px/s | **×0.70** → 140 / 182 px/s | 由 `bulletSpeedMul` 统一缩放 |
| Monstro 蓄力帧（JUMP CROUCH） | 阶段1:30 / 阶段2:18 | **×1.30** → 39 / 23 帧 | 由 `telegraphMul` 统一缩放，给更长预告窗口 |
| 冰锥/弹幕**数量** | 不变 | **不变** | 辅助模式只**降速**，不减数量（保持画面完整） |
| 敌人接触伤害/HP | 不变 | **不变** | 不削弱敌人本体，只降其攻击施加速率 |

**对 `00-concept.md` §6 难度曲线的影响**：辅助模式对所有敌人**等比**降速，房间难度分层（首房→最后房递增）与 Boss 三阶段递进的**相对关系不变**，故心流曲线设计**不被破坏**。可通过。
> 实现：所有敌方子弹速度乘 `ASSIST.bulletSpeedMul`；所有预告/蓄力帧乘 `ASSIST.telegraphMul`。见 `02-combat.md` §5.5 常量定义。

**（2）形状冗余（不靠颜色区分）——逐敌核对**
| 敌人 | 关键状态 | 颜色通道 | **形状/亮度冗余（本作已满足）** |
|------|---------|---------|------------------------------|
| Gaper | 追击/受击 | 肉色 | 蹒跚搓步（**运动**）+ 受击**闪白**（亮度）；巨口大脸轮廓可辨 |
| Pooter | 吐弹预告 | 绿 | 吐弹前**嘴部缩放 1→1.4**（形状，art-bible §2.3②） |
| Horf | 吐弹预告 | 肉色 | 吐弹前**嘴 r 7→10 + 体 scaleY 0.9→1.1**（形状，art-bible §2.3③） |
| Fly | 存在 | 近黑 | 振翅**高频运动** + 小型轮廓 |
| Spider | 扑击预告 | 暗紫 | **前腿收缩**（形状，art-bible §2.3⑤） |
| **Monstro** | 攻击预告 | 变红 | **张嘴 open 0→1**（形状，art-bible §2.4）+ 嘴内**闪光**（亮度，双通道）；阶段 3 额外"喷血线"形状 |

**结论**：本作所有敌人的攻击预告均以**形状变化**（张嘴/缩放/收腿）为主通道，颜色仅作辅助——满足 `accessibility.md` §4 契约，色盲玩家可凭形状/运动预判攻击。

**（3）其他敌人相关契约**
| 契约项 | 落地 |
|-------|------|
| 屏幕震动开关 | Boss 落地 14px 震幅 × `SHAKE.scale`（减弱=0.33/关=0） |
| 闪烁开关 | 敌人受击闪白在关闭档改为**仅描边闪白**，不做全屏白闪 |
| 高对比模式 | 敌人轮廓描边对比增强（art-bible 高对比模式），极暗环境下敌人可辨 |

## 4. 刷怪波规则（Room Encounter Config）

### 4.1 按房间难度的敌人配置（对齐 `01-dungeon.md` 6.2 节奏表）
| 房间位置 | 总敌数 | 组成权重 |
|---------|-------|---------|
| 出生房 | 0 | — |
| 首房（dist=1） | 1–2 | Gaper 100% |
| 中间房 | 2–4 | Gaper 50% / Pooter 30% / Horf 20% |
| 倒数第 2 房 | 3–4 | Gaper 40% / Pooter 30% / Horf 30% |
| 最后普通房 | 3–5 | Gaper 35% / Pooter 35% / Horf 30% |
| Boss 房 | 1（Monstro） | — |

### 4.2 组合公式
```js
enemyCount = clamp(round(1 + distFromStart * 0.6 + rng.range(-1,1)), 1, 5)
// dist=1 → 1.6≈2；dist=4 → 3.4≈3；dist=5 → 4
composition = weightedPick([gaper, pooter, horf], weightsByRoomPos)
```
- **混合规则**：同一房间**至少 1 个近战型**（Gaper/Fly），保证玩家不能纯远程磨；最多 **2 种**敌人类型（避免认知过载，支柱 P3/P4 对应）。
- **数量上限**：单房最多 **5** 个敌人（含 Fly 蜂群时最多 6）。

### 4.3 刷怪位置规则
- 从 `01-dungeon.md` 的 `spawnPoints`（距门 ≥3 tile、不重叠障碍）抽取。
- **不与玩家出生位置重叠**（≥ 2.5 tile 距离）。
- 若房内有岩石，敌人不生成在岩石格内。

### 4.4 层间难度递增（增强层）
```js
// 第 n 层（n≥1）
enemyHpMul   = 1 + 0.25 * (n - 1)     // 第2层 +25%
enemyCountMul= 1 + 0.20 * (n - 1)     // 第2层 +20%
```
- MVP 仅单层，`n=1`，均为 1.0。

```js
Enemy = {
```

## 6. 边缘情况（Edge Cases）

1. **敌人卡在岩石/墙上**：CHASER 用简单避障（撞墙则该轴速度反向或滑行），不做 A* 寻路（成本高）。
2. **Pooter 飞出房间边界**：钳制在可玩区内（`x∈[40+radius, 1000-radius]`）。
3. **Horf 弹幕命中其他敌人**：本方弹幕**不伤友军**（仅伤玩家），简化实现。
4. **Monstro 跳跃落点在玩家身上**：落地判定用**落点冲击波**半径 60px 圆（独立于 §3.1.1 的**本体**碰撞体）；玩家在无敌帧内不受伤。
5. **Monstro 阶段切换时正在跳跃**：延迟到落地后切换（避免空中切换动画错乱）。
6. **敌人全灭但子弹仍在飞**：清房判定**只算存活敌人**（含正在 DYING 的算已死），子弹不阻塞开门。
7. **Boss 死亡时玩家瞬间也死**（同帧）：优先判定**玩家死亡**（玩家死亡优先，游戏结束）。
8. **分裂型敌人（未来）**：子体继承父体 50% HP，且不计入"原房间敌人数"上限（单独计数）。
9. **多个敌人同帧攻击**：各自独立计时器 + 随机抖动，避免齐射瞬秒玩家。
10. **Monstro 与房间满屏弹幕**：同屏弹幕上限 80，超出则不生成新弹（防卡顿）。

## 7. 验收标准
- [ ] Gaper 能稳定追击并造成接触伤害；被击杀有闪白/击退/爆浆。
- [ ] Pooter 保持距离并周期性射击；可越过坑洞。
- [ ] Horf 静止、有蓄力预警、三向弹幕可躲。

- [ ] 清房（含 Boss 死亡）后对应门开启。
- [ ] 敌人不在障碍物内生成。
- [ ] Killet: 300HP Boss 用基础 DPS 可在 60s 内击杀（不卡死）。
