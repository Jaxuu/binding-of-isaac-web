## 1. 游戏支柱（Design Pillars）

支柱是**一切设计决策的仲裁者**。任何新功能若不能至少服务其中一条支柱，就不做。

| # | 支柱 | 一句话定义 | 为什么是它 |
|---|------|-----------|-----------|
| P1 | **手感优先的即时战斗** | 每一次射击、受击、击杀都必须在 100ms 内给出明确的视觉+听觉反馈。 | 以撒的灵魂是"眼泪战争"。没有扎实的双摇杆射击手感，道具和地牢都是空壳。这是所有其他系统的承重墙。 |
| P2 | **Build 建构的化学爆炸** | 道具不是加法，是**乘法**——每拾取一个道具都要能改变你"玩的方式"，而非仅改变数字。 | 原作最有辨识度的体验是"Soap 把它们组合在一起"的顿悟时刻（Brimstone + Inner Eye = 三向激光）。复刻不复刻这一点，等于没复刻。 |
| P3 | **恐惧与荒诞的黑色幽默** | 用粗黑描边的手绘怪诞风，把"以撒家地下室"包装成既令人不安又令人发笑的玩具箱。 | 视觉是低成本 Canvas 项目的最大杠杆。风格一致性比画面精细度更能建立记忆点。 |
| P4 | **短局循环的"再来一把"** | 单局 8–15 分钟，死亡即归零，但每局都解锁新见闻；失败必须是"信息"而非"惩罚"。 | Roguelike 的留存来自快速重开。局时太长会让手机端用户流失。 |

## 2. 核心循环（Core Loops）

四层循环嵌套，外层为内层提供动机，内层为外层提供节奏。

### 2.1 动作级循环（秒级 · 0.5–3s）
```
瞄准 → 射击眼泪 → 命中/落空 → 敌人闪白/击退 → 击杀或被击 → 调整站位 → 再瞄准
```
- 这是 P1 的战场。所有参数（射速帧间隔、弹速、受击硬直）在 `02-combat.md` 定义。

### 2.2 房间级循环（十几秒–1 分钟）
```
进入房间 → 门关闭 → 清除所有敌人 → 掉落概率判定/宝箱开启 → 门开启 → 选择下一个房间
```
- 张力点：清房前的紧张 → 清房后的奖励释放。
- 定义了"遭遇-清空-奖励"的呼吸节奏，是 P4 的最小重玩单元。

### 2.3 层循环（3–6 分钟）
```
探索 5–8 房（含特殊房）→ 找到 Boss 房 → 击败 Boss → 拾取 Boss 掉落 → 下楼梯 → 进入更深层（难度+）
```
- 定义了 P3 的"越陷越深"叙事感与 P4 的进度标尺。

### 2.4 单局循环（8–15 分钟）
```
开始（3 红心，无道具）→ 逐层探索 → 收集 12–18 个道具建构 Build → 死亡或通关 → 结算界面 → 重开
```
- 定义了 P4 的整体弧线：**脆弱开局 → 力量成长 → 极限挑战 → 结局**。

## 3. MDA 分析

### 3.1 Mechanics（机制）
系统层，可编码的规则：
- **双摇杆移动射击**：WASD 八向移动 + 方向键四向独立射击（移动端：左摇杆 + 右射击按钮）。
- **六维属性系统**：Damage / Fire Rate / Range / Shot Speed / Speed / Luck，均支持加法叠加与上下限钳制。
- **道具驱动的眼泪变体**：同一"发射"动作，按装备道具改变投射物行为（激光/抛物/穿透/追踪/散射）。
- **程序化地牢生成**：房间槽位随机 + 邻接图连通性保证 + Boss 房最远约束。
- **清房-开门的房间状态机**：Closed → Open（清空后）→ Locked（特殊房未满足条件时）。
- **敌人行为状态机**：Idle / Chase / Attack / Hurt / Die，按类型分配权重。

### 3.2 Dynamics（动态）
玩家与机制交互后**涌现**的行为：
- **风险-回报走位**：射程有限 + 敌人围堵 → 玩家被迫在"贴脸输出"与"安全风筝"间权衡。
- **Build 寻路**：玩家开始根据已获得道具，主动规划要去的房间类型（找宝箱房还是先拿 Boss 掉落）。
- **资源焦虑**：红心是唯一硬通货（可选实现"心之容器/心之魂"），一次失误的代价被放大 → 谨慎与贪心并存。
- **难度自我调节**：道具强力 → 玩家进攻更激进 → 遭遇更多敌人 → 动态拉升实际难度。

### 3.3 Aesthetics（美学）
用 8 类经典美学关键词（Hunicke 等, "MDA: A Formal Approach"）映射本作体验：

| 美学关键词 | 本作体现 | 强度 |
|-----------|---------|------|
| **Sensation（感官）** | 眼泪命中敌人的爆浆、屏幕震动、闪白，纯粹的血肉质感 | ★★★★ |
| **Challenge（挑战）** | 清房生存、Boss 三阶段弹幕躲避、资源管理 | ★★★★★ |
| **Discovery（探索）** | 程序化地牢每局不同、未知道具效果的揭晓感 | ★★★★ |
| **Narrative（叙事）** | 以撒家地下室的黑色童话氛围（轻叙事，靠环境与道具名暗示） | ★★ |
| **Fantasy（幻想）** | "一个用眼泪对抗怪物的哭泣小孩" —— 荒诞英雄幻想 | ★★★ |
| **Expression（表达）** | Build 组合就是玩法层面的自我表达，每局都是"我的打法" | ★★★★ |
| **Fellowship（社交）** | **不做的**（单人游戏）；未来可选本地双人 | ★ |
| **Submission（沉浸/消磨）** | 短局循环的"再来一把"，低门槛的放松式闯关 | ★★★ |

**核心美学排序：Challenge > Sensation ≈ Discovery ≈ Expression**。所有调参以"难度是否公平、反馈是否爽快"为第一优先。

## 4. 玩家心理学映射（自我决定论 SDT）

| 心理需求 | 定义 | 本作如何满足 | 设计抓手 |
|---------|------|-------------|---------|
| **自主性（Autonomy）** | 玩家感觉行为出于自愿、有选择 | 地牢路线自由探索；道具效果多样且可组合出个人风格；移动端/键鼠双方案 | 房间选择权、Build 自由度、无强制线性路径 |
| **胜任感（Competence）** | 玩家感觉自己在变强、能掌控 | 属性可见增长（六维面板实时变化）；清房正反馈；Boss 击败的阶段性成就；熟练后走位明显更从容 | 属性面板、清房音效、Boss 血条、层数递增 |
| **关联性（Relatedness）** | 玩家感觉与他人/角色有连接 | 以撒的脆弱形象引发保护欲；道具名与 Boss（Mom）暗示的家庭叙事；未来可分享 Build 与成绩 | 角色立绘、道具命名叙事、结算数据可截图分享 |

> **Bartle 玩家类型对齐**：本作主要服务 **Achiever（成就者）** 与 **Killer（杀手→此处指挑战型）**，兼顾 **Explorer（探索者）**；**Socializer** 暂不覆盖（单人）。

## 5. 范围分层（Scope Tiering）

> 精确对齐用户需求：随机地牢 5–8 房 + Boss 房、射击战斗、道具掉落、属性系统、3 种普通敌人 + 1 Boss、WASD 移动 + 方向键射击、移动端虚拟摇杆、开始/死亡/通关三界面（本作含死亡与通关，故为四界面）。

### 5.1 MVP（必做 · Must-Have）
> 判定标准：缺了任何一项，游戏就不成立。

| 模块 | 内容 | 对应交付物 |
|------|------|-----------|
| 渲染与循环 | Canvas 2D 渲染、requestAnimationFrame 主循环、固定时间步（60Hz 逻辑） | `02-combat.md` |
| 玩家 | 以撒角色、3 红心、WASD 八向移动、方向键四向射击 | `02-combat.md` |
| 战斗 | 眼泪投射物、命中判定、无敌帧、击退、屏幕震动 | `02-combat.md` |
| 地牢 | 程序化生成 **总 5–8 房（含出生房）+ 1 个 Boss 房**，Boss 房必须最远，房间网格连通。口径以 `01-dungeon.md` §6.1 为唯一权威 | `01-dungeon.md` |
| 房间 | 清房开门状态机、门朝向、基础岩石障碍 | `01-dungeon.md` |
| 敌人 | **3 种普通敌人**：Gaper（追击）、Pooter（飞行远程）、Horf（静止吐弹） | `04-enemies-boss.md` |
| Boss | **1 个 Boss**：Monstro，含三阶段与跳跃压地 + 三向弹幕 | `04-enemies-boss.md` |
| 道具 | **12–16 个道具**，含眼泪变体（Brimstone/Ipecac/Mom's Knife 等） | `03-items-stats.md` |
| 属性 | 六维属性系统 + 叠加规则 + 上下限钳制 | `03-items-stats.md` |
| 掉落 | 普通击杀掉落、Boss 掉落、宝箱房 | `03-items-stats.md` |
| 界面 | 开始 / 游戏内 HUD / 死亡 / 通关（4 界面） | `05-ux-flow.md` |
| 输入 | 键盘（WASD + 方向键）+ 移动端虚拟摇杆 + 射击按钮 | `05-ux-flow.md` |

### 5.2 增强层（Should-Have · 首版后追加）
- 特殊房：宝箱房（固定）、商店（金币系统）、恶魔房（血量换道具）。
- 更多普通敌人：Fly（苍蝇群）、Spider（蜘蛛）、Mulligan。
- 更多道具至 25–30 个；道具被动外观改动（给以撒加帽子/翅膀）。
- 简易音频：眼泪发射、命中、受击、清房、Boss 咆哮。
- 层数系统：第 2 层及以上，敌人 HP 与数量递增。
- 小地图（Minimap）显示已探索房间。

### 5.3 未来层（Vision · 长期愿景）
- 多角色（Magdalene/Cain/Eve 等，不同初始属性）。
- 成就系统与解锁池。
- 本地双人同屏。
- 每日挑战（固定种子）。
- 完整 8 层 + 多结局（Mom → Mom's Heart → It Lives）。

### 5.4 明确不做（Out of Scope）
- 联网多人、云存档、账号系统。
- 外部美术/音频资源（一切程序化绘制）。
- 复杂过场动画与配音。

## 6. 心流曲线设计（Flow Curve）

### 6.1 单局难度爬升（层内 vs 层间）
```
紧张度
  │                                        ╱╲  ← Boss 战峰值
  │                              ╱╲      ╱   ╲
  │                 ╱╲         ╱   ╲   ╱      ╲__ 结束/通关
  │        ╱╲     ╱   ╲      ╱      ╲_╱
  │  ╱╲  ╱   ╲  ╱      ╲__╱  ← 探索期（低强度，找路）
  │ ╱  ╲╱     ╲╱
  └──────────────────────────────────────────────▶ 时间
   开局  1房  2房  3房  4房  ...  最后房  Boss
```

- **开局（0–20s）**：极低压。1–2 个弱敌，教学式安全（玩家熟悉移动射击）。
- **房 1→N（探索期）**：锯齿状上升。普通房 2–4 敌人；每清一间有一个短暂释放谷。
- **最后房（Boss 前）**：敌人数量/密度达峰值（3–5 敌人或精英），提供"Boss 前的压力积累"。
- **Boss 房**：全曲线最高点。Monstro 三阶段，第二阶段起进入狂暴。

### 6.2 房间-层-Boss 节奏规则
| 位置 | 敌人数量 | 敌人强度 | 说明 |
|------|---------|---------|------|
| 首房（起始房） | 0 | — | 安全出生房，无门锁死 |
| 第 2 房 | 1–2 | 单类型弱敌 | 教学曲线，Gaper 优先 |
| 中间房 | 2–4 | 混合 2 类型 | 主体战斗区 |
| 倒数第 2 房 | 3–4 | 含远程/飞行 | 组合压力测试 |
| 最后普通房 | 3–5 | 全类型混合 | Boss 前压力峰值 |
| Boss 房 | 1（Boss） | Monstro | 阶段化 |

### 6.3 心流保障机制（避免焦虑/无聊）
- **焦虑防护**：每层至少一次回复机会（宝箱房心之掉落 或 恶魔房风险选择）；受击无敌帧给玩家反应窗口。
- **无聊防护**：道具 Build 的重构感维持新鲜度；层间敌人数量递增防止后期碾压。
- **悬崖防护**：Boss 战前不强制战斗，允许玩家"心理准备"（进门瞬间 0.5s 无敌 + 镜头缓入）。

## 7. 待用户审批项
1. **支柱优先级**：本作是否确认以 P1（手感）为最高仲裁？若用户更看重 P2（Build），则道具数量需从 12–16 上调。
2. **层数设计**：MVP 是否只做**单层**（总 5–8 房 + 1 Boss，通关 = 击败 Monstro）？还是首版即含 2 层？→ 建议 MVP 单层，增强层加第二层。
3. **美学定位**：确认 P3 的"荒诞黑色幽默"调性（血液/粪便/眼泪）——是否所有年龄段可接受？如面向低龄需软化。
4. **移动端优先度**：虚拟摇杆是 MVP 硬需求（已列入），但需确认目标设备（手机竖屏 / 平板横屏）以定分辨率。

## 8. 已知风险与取舍
- **风险 R1**：零依赖 + 全程序化绘制 → 美术表现力上限受限。**取舍**：用风格一致性（粗描边 + 高对比色）弥补精细度。
- **风险 R2**：双摇杆在移动端触摸手感天生弱于手柄。**取舍**：射击提供"自动朝向最近敌人"辅助开关（可关闭）。
- **风险 R3**：单层流程偏短（8–15 分钟），可能重玩动力不足。**取舍**：靠 Build 多样性与难度曲线拉高重玩价值。
