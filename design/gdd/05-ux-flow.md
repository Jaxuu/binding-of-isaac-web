## 1. 系统概述
定义 4 个界面的**信息架构与布局栅格**、玩家流程、移动端触摸布局、键盘映射与可访问性。所有界面在 **1280×720** 逻辑画布内绘制（与游戏一致，见 `01-dungeon.md`）。

## 4. 界面 2 · 游戏中 HUD

### 4.1 信息架构
| 区块 | 位置 | 内容 |
|------|------|------|
| 生命值 | 左上 | 红心容器（♥ × 最大血量），半心显示 |
| 六维属性 | 左上（心下方） | 伤害/射速/射程/弹速/移速/幸运 小图标+数值 |
| 道具栏 | 右上 | 已拾取道具图标（32×32，最多显示 8 个，滚动） |
| 小地图 | 右下 | 已探索房间网格 + 当前位置 |
| Boss 血条 | 顶部居中 | 仅 Boss 房显示，红色横条 |
| 暂停按钮 | 右上角 | 触摸/点击暂停 |

### 4.2 布局栅格（1280×720）
```
┌──────────────────────────────────────────────┐
│ ♥♥♥                    [BOSS HP ██████░░]  ⏸ │  ← 生命/属性/Boss条/暂停
│ DMG 3.5  SPD 1.0                       道具栏 │
│ RATE 6.0/s RNG 6.5                            │
│                    ┌────────┐                 │
│                    │ 房间   │  ← 可玩区       │
│                    │ 世界   │    1024×576     │
│                    │        │                 │
│                    └────────┘         ┌─────┐ │
│                                       │迷你 │ │  ← 小地图
│                                       │地图 │ │
└───────────────────────────────────────└─────┘─┘
```
- HUD 占用四周 ≤ 120px（左右）/60px（上下）安全边距。
- 属性面板：每行一个属性，格式 `图标 数值`，字号 16px。

### 4.3 属性显示格式（对齐 `03-items-stats.md` 3.2-6）
| 属性 | 显示 | 示例 |
|------|------|------|
| 伤害 | `DMG {damage.toFixed(1)}` | DMG 6.0 |
| 射速 | `RATE {round(60/fireDelay*10)/10}/s` | RATE 8.6/s |
| 射程 | `RNG {range.toFixed(1)}` | RNG 6.5 |
| 弹速 | `SHOT {shotSpeed.toFixed(1)}` | SHOT 1.0 |
| 移速 | `SPD {speed.toFixed(1)}` | SPD 1.0 |
| 幸运 | `LUCK {luck}` | LUCK 2 |

- **属性变化反馈**：拾取道具瞬间，对应属性条目**高亮放大 + 数值滚动动画 0.5s**。
- **触及钳制上限**：条目闪红边框（对齐 03 3.2-7）。

### 4.4 小地图规格
- 每个已探索房间 = **一个格子**，格子间距 2px。
- 颜色：当前房=黄色描边、已清普通房=灰、已探索未清=深灰、Boss 房=红、未探索=不显示、宝箱房=金。
- 尺寸：每格 **16×16 px**，随地图规模动态排布（当前地图最多 5×5 格 → 80×80px，见 `01-dungeon.md` §2.3）。

## 7. 移动端布局（Touch）

### 7.1 触摸热区（横屏优先）
```
┌──────────────────────────────────────────────┐
│ ♥♥♥                            [BOSS ███]  ⏸ │
│                                              │
│  ╭───────╮                          ╭─────╮  │
│  │ 左摇杆 │        游戏区            │射击 │  │
│  │  (移动)│                          │ 按钮 │  │
│  ╰───────╯                          ╰─────╯  │
│                                              │
└──────────────────────────────────────────────┘
```
| 控件 | 位置 | 尺寸 | 说明 |
|------|------|------|------|
| 左虚拟摇杆 | 左下角 | 半径 **90px** 底盘 + 40px 摇杆头，触摸热区 180×180 | 控制移动（连续方向） |
| 右射击区 | 右下角 | 触摸热区 **160×160** | 按下即朝摇杆方向射击（或朝最近敌人） |
| 暂停键 | 右上角 | 48×48 | — |

### 7.2 摇杆实现规范
- **死区**：摇杆位移 < 25% 半径 → 视为无输入。
- **动态归位**：手指按下点成为摇杆中心（不固定，提升手感）。
- **射击辅助**：右区按下时，若开启"辅助瞄准"，射击方向 = 朝最近敌人的方向（可关）。
- **多点触控**：必须支持（左拇指移动 + 右拇指射击同时）。

### 7.3 触摸事件要点
- 使用 `touchstart/touchmove/touchend` + `pointer events` 兜底。
- `touch-action: none` 防止浏览器滚动/缩放。
- 全屏 API 调用（可选）以隐藏浏览器 UI。

## 9. 可访问性（Accessibility）

| 项目 | 方案 | 优先级 |
|------|------|-------|
| 屏幕震动开关 | 设置中提供"关闭屏幕震动" | 高 |
| 闪烁频率 | 无敌帧闪白限制 ≤ 6Hz（防光敏癫痫） | 高 |
| 颜色对比 | 红心/道具图标保证对比度 ≥ 4.5:1 | 中 |
| 文字大小 | 支持 1×/1.5× 字号切换 | 中 |
| 单手操作 | 移动端摇杆可镜射左右 | 低 |
| 音效字幕 | 关键音效提供视觉替代（如 Boss 咆哮=屏幕波动） | 低 |

> 对齐 `design/accessibility-requirements.md`（若后续创建）。

## 10. 边缘情况（Edge Cases）

1. **窗口尺寸 ≠ 16:9**：letterbox 黑边，保持逻辑 1280×720 比例；触摸坐标需做逆变换。
2. **旋转屏幕（移动端）**：仅支持横屏；竖屏时显示"请横屏游玩"遮罩。
3. **失焦**：自动暂停 + 显示暂停面板。
4. **结算界面数据缺失**：若某统计未初始化，显示 0（不崩）。
5. **小地图超过栅格**：动态缩小格子到 12px。
6. **道具栏超 8 个**：显示前 8 个 + "+N"。
7. **触摸与键盘同时**：以最后有效输入源为准，不冲突。
8. **暂停中点击暂停按钮**：恢复游戏。
9. **Boss 血条在非 Boss 房**：隐藏（不占位）。
10. **死亡界面按 R 立即重开**：清空所有局内状态（新 RNG seed）。

## 11. 验收标准
- [ ] 四个界面均可在 1280×720 内完整显示，无溢出。
- [ ] 开始→游戏→死亡→重开 流程闭环。
- [ ] HUD 六维数值随道具拾取实时更新。
- [ ] 移动端双拇指同时操作移动+射击正常。
- [ ] 死亡界面 4 项统计准确。
- [ ] 失焦自动暂停。
