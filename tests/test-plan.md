## 0. 测试环境与约束

| 项 | 约束 |
|----|------|
| 技术栈 | 原生 HTML5 Canvas 2D + 原生 ES Modules，零依赖零构建 |
| 加载方式 | **必须走 HTTP**（`python -m http.server`）。ES Module 在 `file://` 下会被 CORS 拦截 → 必然白屏 |
| 浏览器 | 系统 Chrome `--headless=new` / **Playwright Chromium**（`playwright` 已随 devDependency 安装，可编程控制真实墙钟） |
| **真实用户路径（权威判定路径）** | ✅ **Playwright Chromium 真实墙钟**（`tests/smoke.mjs` / `tests/qa-probe.mjs realtime`）——等价用户真实浏览器，**一切截图判读以此为准** |
| **禁用路径（仅限粗检，不得作发布证据）** | ⚠️ 系统 Chrome `--headless=new --virtual-time-budget=N`（`tests/shoot.sh`）。该路径在**加载期**推进虚拟时钟但**饿死 rAF**（实测 40s 预算仅跑 5~6 帧 → `trans=0.12`），截图**只是加载首帧残留**，会误报"卡在 FLOOR_INTRO / 角色半截"。**仅可用于"加载是否成功/是否白屏"的粗检。** |
| 逻辑单测 | `node tests/run.cjs`（纯 Node，无浏览器） |
| ESM 依赖图 | `node tests/lint-esm.cjs src` |

> **方法论纪律（v2.0 更正）**：v1.0 曾将"系统 Chrome + `--virtual-time-budget`"列为权威路径，并据此误判 BUG-002/003 为 Blocker。**真实用户从不使用虚拟时间**；**权威路径是真实墙钟**。发现"卡住/半截/黑屏"时，**必须先换真实墙钟路径复现**，再判定是否为游戏缺陷（受控 A/B：同页真实墙钟 2.0s 进 PLAYING）。
> 关于 `tests/harness.mjs`：其使用 Playwright 真实墙钟，**与权威路径一致**，其 PASS 结果**可作证据**（v1.0 的"其 PASS 不能代表真实路径"结论已**证伪并撤销**）；仍建议以 `tests/smoke.mjs` 为门控基线。

**测试类型分层**：
1. **逻辑测试（自动）** — Node 纯函数级（地牢/属性/碰撞/掉落/RNG）。
2. **集成测试（自动）** — 真实浏览器内驱动完整链路（Input→Player→Combat→Enemy→Pickup）。
3. **视觉/渲染测试（自动+人工）** — 截图 + 文字描述判读（对抗"代码里有函数但画面没发生"）。
4. **烟雾门控（自动）** — 启动即检：无控制台错误 + canvas 有内容 + 进入 PLAYING + FPS 合理。
5. **Playtest（人工）** — 新玩家体验/中盘系统/难度曲线（本迭代未组织真人，留占位）。

## 3. 烟雾门控范围（Smoke Gate）

每次提交/发布前必跑（`node tests/smoke.mjs`，**真实墙钟路径**），任一 FAIL = 未达 QA：
1. HTTP 加载 `index.html` → **无控制台错误**（AudioContext autoplay 警告可豁免，非错误）。
2. canvas **有实际内容**（非纯色空白）。
3. 能**进入 PLAYING**（`scene === 'playing'`，真实墙钟等待后判读；不卡 TITLE / FLOOR_INTRO）。
4. FPS 读数存在且 ≥ 30（真实时间下）。

> **门控路径纪律**：判据 3「进入 PLAYING」**只能**在真实墙钟路径下判读；`--virtual-time-budget` 会饿死 rAF，**不得**用于该项（否则必误报 FAIL）。
> 当前基线：`smoke.mjs` → **PASS**（`scene=playing`、fps=60、canvas 268 色）。

## 5. 退出准则（Exit Criteria）

发布候选需同时满足：
- **无 Blocker / Critical 未决 Bug**（当前：**满足**——BUG-002/003 关闭，BUG-004 已修）。
- 所有 **P0** 用例通过（或经用户书面接受）。
- 烟雾门控 **PASS**（`node tests/smoke.mjs`，真实墙钟路径）。
- 自动测试：ESM lint PASS、逻辑单测全通过、地牢不变量 0 违规、三种敌人可生成。
- 关键路径（开始→战斗→清房→Boss→结算）在**真实墙钟路径**下人工确认。
